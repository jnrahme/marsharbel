## Source register and limits
Sources read October 16, 2026. These are study sources, not permissions to reuse photographs.

1. https://bible.usccb.org/bible/Isaiah/6
   Scriptural vision: six wings per seraph if represented literally. No robe edge, body or face of God in our illustration. Use empty luminous holy space or a fully covered empty throne. Winged vision forms are not generic two-winged human angels.
2. https://bible.usccb.org/bible/1kings/6
   First Temple literary details support dressed stone, cedar, wood paneling and a bounded sanctuary. The USCCB note explicitly says the text cannot yield a satisfactory exact model. Therefore no claim to an accurate Temple reconstruction, no later Herodian facade, Roman columns or medieval cathedral.
3. https://www.britishmuseum.org/collection/object/W_1856-0909-14
   Museum object 124905, Lachish assault relief, Neo-Assyrian, 700-692 BC. Context for Assyrian siege equipment. The violent narrative is NOT adopted for a child's illustration. Metadata read, actual object image not visually verified because the public image is unavailable/403 here.
4. https://www.britishmuseum.org/collection/object/W%5F1856-0909-14%5F3
   Museum object 124907: Judaean families, goods, animals, shields, chariot and other objects in the Lachish relief. Metadata read; costume pixels not yet inspected. Do not claim garment/helmet details are visually locked from this record alone.
5. https://www.avilaturismo.com/que-ver/monasterio-de-la-encarnacion
   Municipal tourism record: early-sixteenth-century monastery around a central courtyard/two-story cloister. Today's church interior was altered in the eighteenth century; the bell gable is from 1715. Exclude those later elements from Teresa's scenes. Use a restrained plain courtyard/interior, not today's baroque chapel as if it existed in 1535.
6. https://teresavila.com/entrada/habito-carmelita/
   T. Alvarez's Carmelite reference cites the Incarnation clothing rite: habit, belt, veil, white cloak and prayer beads. Separately quotes Teresa's reform Constitutions 4:2: coarse dark cloth, narrow unpleated sleeves, matching scapular, white choir cloak, simple headcloth and espadrilles. These are separate wardrobe records, not a single uniform retroactively applied to every age.
7. https://teresavila.com/ficha/el-monasterio-de-santa-maria-de-la-encarnacion/
   Incarnation community had black-veiled choir nuns and white-veiled lay sisters. Some entry/profession dates differ across secondary histories; no new exact-date scene or clothing ceremony is introduced. The page itself has an obvious "1335" typo; it is not adopted. The accepted narrative stays with Vatican's age-20 entry, not a newly invented date.
