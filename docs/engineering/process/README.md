# Lane process pack (adopted 2026-10-02, Joey approved)

Four small conventions. Concepts only, no third-party tooling.

| # | Convention | Applies to | Doc |
|---|---|---|---|
| 1 | Spec-first PR template | LARGE builds only | [spec-first.md](spec-first.md) |
| 2 | Corrections-to-rules loop | every Joey correction | [corrections-loop.md](corrections-loop.md) |
| 3 | Independent reviewer | big features | [independent-review.md](independent-review.md) |
| 4 | Resume checkpoint file | long builds | [checkpoints.md](checkpoints.md) |

Routine content and storybook work skips 1, 3 and 4. Item 2 always applies.
These add to, never replace, the golden rule and merge gate in `AGENTS.md`.
