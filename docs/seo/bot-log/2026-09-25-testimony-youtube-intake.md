# Optional YouTube link on reader testimony intake, September 25, 2026

The form now accepts an optional YouTube video URL with a written account. Browser and server accept HTTPS watch, short, live and embed URLs from exact YouTube hosts only; the server stores an eleven-character video ID, not an arbitrary URL. Empty links remain valid. Guest intake still requires CAPTCHA, age, publication and screening consent, plus the existing 60-character written account. The form explains that a reviewer will check video suitability and permission before publication.

A new additive Supabase migration adds private and public projection video ID columns, wires guest/account intake, edits and human approval, and preserves the existing rate limits and moderation safeguards. The moderation queue links to the submitted video for human review. Only an approved row gains a public video ID; `/testimonies` builds a lazy `youtube-nocookie.com` iframe from that checked ID alongside the account text. Withdrawal, edits or unpublish remove the public projection. The historical source-published archive remains separate.

Deploy migration and updated site/Edge function together. Apply the migration before the new frontend and Edge function, or submissions with a video would fail while the database still lacks the column. This patch does not deploy the Supabase migration or change production data. Existing stories have null video IDs. There is no evidence that a submitted video is truly owned by the submitter merely because its URL is syntactically valid; moderators must inspect video content, consent, and any identifiable people before approval. Embedded third-party video may set YouTube cookies or load resources when viewed; the iframe is lazy and privacy-enhanced but is not a first-party video.

Tests: SQL migration rerun, private/public projection, approval/unpublish and edit; server URL validation and Edge intake; browser submission and moderator/public rendering; i18n policy; SEO and static archive checks. Screenshots of the form were inspected at mobile and desktop widths.
