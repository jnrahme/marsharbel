# 2026-09-25 - Portuguese prayer mirror

`/pt/oracoes` replaces its short guide only after rendering the English prayer master through the 114-slot Portuguese catalog. It retains the English page's seven visible sections, historic photo, 14 prayer cards, seven full Rosary prayers, buttons, responsive layout and source labels. Its existing canonical, reciprocal hreflang cluster and sitemap listing are maintained. The generator owns this page; edit `locales/pt/mirrors/prayers.json`, not the HTML. The renderer now uses a single reviewed-locale list instead of a new set of route/catalog variables per rollout language. Italian, German and Polish guides remain short pending their own parity checks.

The Saint Charbel intercession prayers, novena framework and brief invocations are translated original compositions of this site, not monastery-published liturgy. Portuguese Rosary forms were checked against the [Vatican News Apostles' Creed](https://www.vaticannews.va/pt/oracoes/simbolo-dos-apostolos.html), [Vatican Pontifical Council Portuguese Rosary](https://www.vatican.va/roman_curia/pontifical_councils/migrants/Rosario/rc_pc_migrants_rosario_po.html), [Vatican News Salve-Rainha](https://www.vaticannews.va/pt/oracoes/salve-rainha.html), and [Fátima Sanctuary's terço](https://www.fatima.pt/pt/pages/terco) and [Fátima prayers](https://www.fatima.pt/pt/pages/oracoes-de-fatima). The closing collect is an independently translated devotional form of the English master's closing text; available Portuguese Rosary references use different closing prayers and the wording should not be presented as an official edition. The English page's Apostles' Creed is retained, not replaced by the Nicene Creed. No healing or miracle is promised.

Checks: `npm run i18n:check`, `python3 scripts/qa/check_seo.py`, eight structural/negative mirror tests and 86 laptop Playwright tests passed locally. Inspected full-page desktop (1366px) and mobile (390px) screenshots, including readable hero/photo, novena, Rosary and footer; no horizontal overflow. Shared chrome still contains an English language-selector label and footer utility links, inherited from the English page. After integration and deployment, capture production EN/PT desktop and mobile pairs and verify the route and selector.
