# 2026-09-25 - Spanish prayer mirror

`/es/oraciones` now renders through the English prayer master template instead of the short Spanish guide. The Spanish catalog has all 114 keyed slots and retains the seven visible page sections, historic photo, 14 cards, seven full Rosary prayers, top navigation, page interactions and source labels. Canonical `/es/oraciones`, the existing reciprocal hreflang cluster and sitemap entry remain intact. The generator owns the output; edit `locales/es/mirrors/prayers.json`, not `es/oraciones.html`. Other languages' shorter guides remain in place until each mirror passes separately.

The intercession prayers, novena outline and brief invocations are translated original site compositions, not text published by the monastery. The traditional prayers were cross-checked against [EWTN's Spanish common prayers](https://www.ewtn.com/es/catolicismo/devociones/oraciones-comunes-20480), [the Vatican's Spanish Rosary guide](https://www.vatican.va/special/rosary/documents/misteri_sp.html) and [Association of the Miraculous Medal's Rosary closing prayer](https://amm.org/es/ore-con-nosotros/oraciones-especiales-2/oracion-despues-del-rosario/). The Apostles' Creed is retained rather than the Nicene Creed; local wording variants exist, so this is not presented as an official Spanish edition. No healing or miracle is promised.

Checks: `npm run i18n:check`, `python3 scripts/qa/check_seo.py`, seven structural/negative mirror tests and 84 local browser tests on the laptop project passed. Local desktop 1366px and mobile 390px full-page screenshots were inspected, including readable hero, image, novena, seven Rosary texts, source/footer and no horizontal overflow. The UI still has the shared English-language selector label and inherited English footer utility links; those match the current English page, but may deserve a separate sitewide chrome translation pass.
