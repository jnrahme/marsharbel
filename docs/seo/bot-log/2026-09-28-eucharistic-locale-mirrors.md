English source: corrected v3 `1e0ec7e`, not earlier v2. The source builder now adds a reciprocal nine-entry hreflang cluster to each English page. International build adds the 42 localized URLs to sitemap and language-switch routing. Runtime-only language options are not published. A nested `.htaccess` preserves directory indexes on LiteSpeed.
