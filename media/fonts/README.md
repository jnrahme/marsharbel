# Website fonts

Cormorant Garamond (500–700) and Manrope (400–800), normal variable WOFF2 fonts, retrieved from the Google Fonts CSS API on 2026-09-22. All offered Unicode subsets are retained; browsers load only subsets needed by the page. Original typefaces and weights are unchanged.

Source: https://fonts.googleapis.com/css2?family=Cormorant+Garamond:wght@500..700&family=Manrope:wght@400..800&display=swap

Font filenames are versioned. If font bytes change, use new filenames to avoid stale browser or service-worker caches. Declarations live in styles.css; Latin subsets are preloaded by each page.
