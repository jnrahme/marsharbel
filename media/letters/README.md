# Letters globe assets

- `flags-sprite.webp`: flags rasterized from flag-icons 7.2.3 (4x3 set), MIT license. License text: `FLAG-ICONS-LICENSE.txt`. Source: https://github.com/lipis/flag-icons
- `world-110m.json`: country outlines from the world-atlas npm package 2.0.2 (ISC license, Copyright 2013-2019 Michael Bostock; full text in `WORLD-ATLAS-LICENSE.txt`), built from Natural Earth (public domain). Source: https://github.com/topojson/world-atlas and https://www.naturalearthdata.com/
- `letters-countries.json`: our own data. Country names come from the list published at saintcharbel.net.au/letters (99 names), plus Canada; pins are approximate capitals or centroids.
