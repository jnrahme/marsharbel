# MarCharbel SEO Plan (2 Weeks)

## Goals
- Increase indexing and visibility for core pages.
- Improve click-through rate from Google results.
- Build first wave of relevant backlinks.

## Priority URLs
- `https://marsharbel.com/`
- `https://marsharbel.com/story`
- `https://marsharbel.com/history`
- `https://marsharbel.com/miracles`
- `https://marsharbel.com/rosary-visual-guide`
- `https://marsharbel.com/testimonies`

## Week 1 (Technical + Content Foundation)

### Day 1
- Confirm Search Console property ownership.
- Submit sitemap: `https://marsharbel.com/sitemap.xml` (or active fallback sitemap).
- Run URL Inspection + Request Indexing for all priority URLs.

### Day 2
- Verify each priority page has:
  - Unique title
  - Unique meta description
  - Canonical tag
  - Open Graph tags
  - `index,follow` robots tag
- Keep utility pages on `noindex` (`submit-testimony`, `testimony-review`, etc.).

### Day 3
- Add/expand one FAQ section on:
  - `/miracles`
  - `/rosary-visual-guide`
- Use clear question headings and concise answers.

### Day 4
- Strengthen internal linking:
  - Homepage links to all priority URLs.
  - `story`, `history`, `miracles`, `rosary-visual-guide` cross-link each other contextually.
  - Add descriptive anchor text (avoid "click here").

### Day 5
- Publish 1 new long-form page (800-1200 words) targeting:
  - `saint charbel story`
  - `saint charbel miracles`
  - `how to pray rosary`
- Include 3-5 internal links to priority URLs.

### Day 6
- Optimize images on priority pages:
  - Descriptive alt text
  - Compressed image sizes
  - Ensure strong social preview image (`1200x630`) for shared links.

### Day 7
- Check Search Console:
  - `Pages` report for indexing status
  - `Performance` baseline (clicks, impressions, CTR, average position)
- Record baseline metrics in this file (append a small log).

## Week 2 (Authority + Distribution)

### Day 8-9
- Publish 2 supporting articles:
  - One around Saint Charbel testimony themes.
  - One around Rosary meditation practice.
- Link both to priority URLs.

### Day 10-11
- Build 5-10 external mentions/links:
  - Church/community directories
  - Relevant Catholic communities/groups
  - Social profiles (YouTube, Instagram, Facebook page, X)
  - Medium/Substack post referencing your key pages
- Prefer branded anchors like "MarCharbel" or page-specific titles.

### Day 12
- Submit one press-style update post:
  - "New interactive Saint Charbel story and rosary resources"
- Link to `/story`, `/rosary-visual-guide`, `/miracles`.

### Day 13
- Re-run URL Inspection for any important page still not indexed.
- Request indexing again after content updates.

### Day 14
- Review Search Console deltas vs Week 1 baseline:
  - Indexed pages count
  - Impressions
  - Clicks
  - CTR
  - Top queries
- Decide next month’s content cluster based on top-performing queries.

## KPI Targets (First 30 Days)
- Core pages indexed: 6/6
- Total indexed pages: +30% vs baseline
- Impressions: +50% vs baseline
- CTR on branded queries: >8%
- 5-10 quality external links acquired

## Weekly Checklist
- [ ] Sitemap status healthy in Search Console
- [ ] New/updated content published this week
- [ ] Internal links added from new pages
- [ ] At least 2 new external mentions/links
- [ ] URL Inspection done for major updates

## Notes
- Sitemaps box is only for sitemap files, not page URLs.
- Individual page URLs must be submitted via URL Inspection.
